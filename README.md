# BoredBot API

A simple web app that fetches random activities using the [Bored API](https://www.boredapi.com/) to help users find something fun to do. Built with **HTML**, **CSS**, and **JavaScript**, this project focuses on API integration and basic frontend interaction.

> 💡 No AI was used in the development of this project. AI tools were utilized solely for documentation purposes, such as generating this README. I believe in building a strong foundation in programming while also learning how to effectively use AI tools as part of a modern developer workflow.

## ✨ Overview

This project demonstrates:

- Fetching data from a public API
- Dynamically updating the DOM based on user interaction
- Basic styling with CSS
- Responsive design principles

## 🌐 Live Site

Check out the live version here: [https://boredbot-intro-to-api.netlify.app](https://boredbot-intro-to-api.netlify.app)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- [Bored API](https://www.boredapi.com/)
